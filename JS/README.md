## Organização do diretório

### Desafio
Aqui está os critérios para a entrega da tarefa da EBAC e relatório final sobre os resultados, incluindo abordagens e ações para aumentar a cobertura de testes.

### aulas
Principais classes para servirem de base nos testes unitários.

### coverage
Arquivos gerados automaticamente pelo sistema de teste automatizado.

### unit-tests
Aqui está os arquivos para implementar os testes unitários das aulas e respostas do Desafio. A referência é preservada pela utilização do `require`.
